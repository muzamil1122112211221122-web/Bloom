# BLOOM — Haute Parfumerie & Couture Rouge

A premium luxury lipstick 3D scroll-driven website experience.

## ✨ Experience Highlights
- **Cinematic Canvas Frame Scrubbing**: 373 pre-extracted ultra-high-definition frames synchronized with scroll progress.
- **GSAP & ScrollTrigger Motion Choreography**: Pinned horizontal craftsmanship rail, vertical reverse-column parallax, and typography reveals.
- **Lenis Smooth Scrolling**: Calibrated smooth scrolling physics.
- **Sticky Bloom-to-Bullet Explainer**: Multi-stage botanical alchemy transitions.
- **Couture Aesthetics**: Deep caviar-burgundy palette (`#0a0506`), warm candlelight ivory (`#f5ece6`), and satin rose-gold (`#c9a675`).

## 🚀 Getting Started
Open `index.html` directly in your browser or run a simple local web server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## 📁 Structure
- `index.html` — Single-file web application architecture
- `frames/` — 373 hero scroll sequence frames
- `images/` — High-resolution botanical and product campaign assets
- `videos/` — Looping craftsmanship atelier clips
